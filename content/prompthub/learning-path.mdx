## 이 경로를 관리하는 기준

- `필수`는 다음 단계 전에 알아야 하는 문서입니다.
- `심화`는 구현 선택과 내부 동작을 더 깊게 볼 때 읽습니다.
- `참고`는 장애·리뷰·과거 판단을 확인할 때 사용합니다.
- 현재 코드와 맞지 않는 문서는 경로에서 제거하거나 참고로 내리고, 대체 문서를 연결합니다.
- 단계 순서는 기능 목록이 아니라 실제 사용자 요청과 데이터가 이동하는 순서를 따릅니다.

<details>
<summary>프로젝트가 추가되면 어떻게 관리하나요?</summary>

`content/{project}/project.mdx` 옆에 `learning-path.mdx`를 하나 추가합니다. `stages`에 학습 목표와 기존 콘텐츠 참조를 적으면 학습 경로 목록과 상세 페이지가 자동으로 생성됩니다. Study 화면이나 React 코드를 프로젝트마다 수정하지 않습니다.

</details>
