## List는 순서가 있는 값의 모음이다

```java
List<String> tasks = new ArrayList<>();
tasks.add("문서 읽기");
tasks.add("코드 확인");
tasks.add("테스트 실행");
```

`List`는 순서가 있고 같은 값을 여러 번 저장할 수 있다. `ArrayList`와 `LinkedList`는 모두
List를 구현하지만 내부 저장 방식이 다르다.

## ArrayList는 배열로 저장한다

```text
인덱스      0           1           2
        [문서 읽기] [코드 확인] [테스트 실행]
                         ▲
                      get(1)
```

인덱스를 알면 해당 위치로 바로 이동하므로 `get(index)`는 O(1)이다. 맨 뒤 추가는 공간이
부족할 때 배열을 늘리는 비용까지 여러 추가에 나눠 보면 분할상환 O(1)이다.

중간에 `X`를 넣으려면 뒤 원소를 옮긴다.

```text
[A][B][C][D] → [A][B][ ][C][D] → [A][B][X][C][D]
```

## LinkedList는 연결로 저장한다

```text
[A] ⇄ [B] ⇄ [C] ⇄ [D]
```

`C`를 찾으려면 가까운 끝에서 연결을 따라간다. 따라서 `get(index)`는 최악 O(n)이다.

`B`와 `C` 사이에 `X`를 넣는 연결 변경 자체는 간단하다.

```text
[B] ⇄ [C] → [B] ⇄ [X] ⇄ [C]
```

하지만 `add(index, value)`는 먼저 그 위치까지 찾아야 하므로 전체 비용은 O(n)이 될 수 있다.
“LinkedList는 중간 삽입이 항상 빠르다”가 아니라 **위치를 이미 가리키고 있을 때 연결 변경이
빠르다**고 구분해야 한다.

| 작업 | ArrayList | LinkedList |
|---|---:|---:|
| `get(index)` | O(1) | O(n) |
| 맨 뒤 추가 | 분할상환 O(1) | O(1) |
| 맨 앞 추가 | O(n) | O(1) |
| `add(index, value)` | O(n) | 위치 탐색 때문에 O(n) |
| 전체 순회 | O(n) | O(n) |

<details>
<summary><b>🔍 ArrayList와 LinkedList 중 무엇을 선택할까?</b></summary>

일반적인 목록 처리라면 ArrayList부터 검토한다. 인덱스로 읽거나 전체를 순서대로 읽고, 주로
맨 뒤에 추가하거나 결과를 정렬하는 작업에 잘 맞는다.

LinkedList는 iterator가 이미 가리키는 위치 주변을 반복해서 삽입하거나 삭제하는 경우에 검토할
수 있다. 단순히 “삽입과 삭제가 많다”는 이유만으로 선택하지 않고 위치 탐색 비용도 포함해야 한다.

</details>

## 큐가 필요하면 ArrayDeque도 비교한다

큐는 **먼저 들어온 항목을 먼저 처리하는 구조**다. FIFO(First In, First Out)라고 부른다.

```text
접수: 주문 A → 주문 B → 주문 C
처리: 주문 A → 주문 B → 주문 C
```

Java에서는 `ArrayDeque`를 큐로 사용할 수 있다.

```java
Deque<String> orderQueue = new ArrayDeque<>();
orderQueue.addLast("주문 A");
orderQueue.addLast("주문 B");
String nextOrder = orderQueue.removeFirst();
```

```text
앞에서 꺼냄 ← [주문 A][주문 B][주문 C] ← 뒤에 넣음
```

<details>
<summary><b>🔍 큐는 언제 필요하고 ArrayDeque는 무엇인가?</b></summary>

큐는 접수된 작업, 다운로드, 프린터 출력처럼 먼저 들어온 일을 먼저 처리할 때 사용한다.

`Deque`는 양쪽 끝에서 넣고 꺼낼 수 있는 Double-Ended Queue다. 뒤에 넣고 앞에서 꺼내면 일반
FIFO 큐가 되고, 같은 쪽에서 넣고 꺼내면 마지막에 넣은 항목을 먼저 꺼내는 스택으로도 쓸 수 있다.

`ArrayDeque`는 한 Java 프로그램의 메모리 안에서 사용하는 자료구조다. Kafka 같은 메시지
시스템은 프로세스나 서비스 사이에서 저장, 전달, 장애 복구와 재처리까지 담당하므로 범위가 다르다.

</details>

## 프로젝트에서는 왜 ArrayList를 쓰나

검색 순위 코드는 입력 목록을 `ranked.get(i)`로 읽고, 후보 목록을 점수순으로 정렬한다.
ArrayList는 이런 인덱스 접근과 정렬에 알맞다. 같은 반복문에 LinkedList를 전달하면 각
`get(i)`마다 연결을 다시 따라가 전체 반복 비용이 O(n²)이 될 수 있다.
