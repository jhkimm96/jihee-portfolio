## 서비스와 문제

지원자 현황부터 합격자와 제출서류 관리까지 대학의 입시 업무를 처리하는 시스템입니다. 여러 업무 화면이 같은 지원자 정보를 다루기 때문에 화면별 데이터 처리 기준을 이해해야 했습니다.

## 내가 맡은 일

Nexacro와 Java·SQL로 지원자 세부정보, 전적대학 정보, 합격자 관리, 제출서류와 기관 관리 기능을 개발했습니다. 개인정보를 다루는 화면에는 기존 암호화 요구사항을 반영했습니다.

## 확인한 결과와 한계

담당 입시 업무 화면과 데이터 처리 기능을 구현했습니다. 운영 지표나 정량 성능 개선은 확인되지 않았으므로 개인 성과로 주장하지 않습니다.
