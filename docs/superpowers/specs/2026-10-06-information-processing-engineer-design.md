# 정보처리기사 실기 학습 허브 설계

## 목적

포트폴리오의 Study 안에 공개 정보처리기사 실기 학습 허브를 만든다. 사용자는 2주 동안 하루 4시간씩 학습하며, 최신 복원 기출을 풀고 자동 채점·오답 복습·암기카드로 합격 가능성을 높인다. 이후 빅데이터분석기사와 SQLD를 같은 구조로 확장한다.

## 확정된 제약과 성공 기준

| 항목 | 결정 |
|---|---|
| 공개 경로 | `/study/certifications/information-processing-engineer` |
| 인증·서버 | 없음. 공개 콘텐츠와 브라우저 내 개인 학습 기록을 분리한다. |
| 학습 시간 | 정보처리기사 하루 4시간. Python 코딩테스트 1시간은 별도이며 이 페이지에 넣지 않는다. |
| 일정 | 날짜 없는 필수 10일 + 여유 4일. 쉬는 날에도 계획이 밀리지 않게 한다. |
| 현재 수준 | 최신 기출 예상 30점. 목표는 최종 모의고사 70점 안전선이다. |
| 최우선 약점 | C 포인터·더블포인터, 보안, 네트워크, 운영체제. |
| 상대 강점 | SQL, Java, Python, C 순으로 약해진다. 단 C의 포인터 계열은 별도 최우선이다. |
| 기출 범위 | 2024년 1회~2026년 2회, 8회차 160문제. 기존 140문제를 유지하고 2026년 2회 20문제를 추가한다. |
| 문제 정확성 | 기출 문장·코드·조건·출력은 바꾸지 않는다. 표·ERD·UML·토폴로지는 페이지 안에서 재현하고 원문 링크를 남긴다. |
| 채점 | 이론은 공백·대소문자·한글/영문 별칭을 정규화해 채점한다. 코드 출력은 줄바꿈·공백·소수점까지 엄격 채점한다. |
| 사용 환경 | 데스크톱과 휴대폰 모두 지원한다. |

## 정보 구조

포트폴리오의 공통 헤더를 유지한 한 개의 자격증 페이지를 만든다. 본문은 탭으로 나눈다.

```text
정보처리기사 실기
├─ 오늘 학습
├─ 10일 플랜
├─ 개념
├─ 기출
├─ 오답
├─ 암기카드
└─ 자료실
```

- **오늘 학습**: 마지막 미완료 필수 Day, 4시간 학습 순서, 오늘 재풀이할 오답을 표시한다.
- **10일 플랜**: 필수 Day 10개와 여유 Day 4개를 표시한다. 여유 Day는 휴식, 밀린 Day, 오답 복습, 모의고사 중 현재 상태에 맞는 작업을 제안한다.
- **개념**: PDF 기반의 짧은 설명을 `1회독 필수 → 2회독 안전선 → 보충 학습`으로 나눈다. 블로그의 상세 자료는 새 탭 링크로 연결한다.
- **기출**: 회차별 연습 모드와 150분 모의고사 모드를 제공한다. 모의고사는 시간이 끝나면 자동 제출·채점한다.
- **오답**: 틀린 문제, 입력 답, 정답, 선택한 오답 이유, 개인 메모, 다음 복습일을 모은다.
- **암기카드**: 오답의 핵심 규칙을 앞면 키워드·뒷면 규칙으로 빠르게 회독한다.
- **자료실**: 블로그 전체 목차, 연도별 기출 원문, 주제별 상세 글을 모은다.

모바일에서는 `오늘 학습 · 기출 · 오답 · 암기카드 · 더보기` 다섯 개 이하의 하단 메뉴를 사용한다. 더보기에 플랜, 개념, 자료실, 백업을 둔다.

## 10일 학습 플랜

| Day | 4시간의 핵심 목표 | 필수 산출물 |
|---|---|---|
| 1 | 2026년 2회 150분 진단 + 오답 분석 | 영역별 최초 정답률 |
| 2 | C 배열·주소·포인터 기초 | 포인터 규칙 카드 |
| 3 | C 더블포인터·구조체·함수 포인터 | 포인터 오답 재풀이 |
| 4 | Java 상속·오버라이딩·`super`·접근제어 | Java 출력 함정 규칙 |
| 5 | Python 슬라이싱·컬렉션·얕은 복사 | Python 추적 오답 회수 |
| 6 | SQL 조인·NULL·집계·서브쿼리 | SQL 결과값 문제 풀이 |
| 7 | 네트워크·서브넷·라우팅 | 서브넷 계산 규칙 |
| 8 | 운영체제·보안 | 스케줄링·보안 암기카드 |
| 9 | DB 설계·SW 설계·테스트 | 핵심 키워드 회수 |
| 10 | 최신 회차 모의고사 + 약점 보완 | 70점 안전선 점검 |

여유 Day 4개는 일정상 날짜에 고정하지 않는다. 남은 오답과 진단 결과를 기반으로 C 포인터, 보안·네트워크·운영체제, 또는 최신 기출 재풀이를 우선 제안한다.

## 데이터와 상태

문제 데이터와 화면 코드를 분리한다. 문제마다 최소한 다음을 가진다.

```text
session, number, domain, prompt, visual, answers, aliases,
gradingMode, explanation, memoryRule, sourceUrl, sourceStatus
```

- `visual`은 표·도식·코드 블록 등 문제를 풀기 위한 원문 재현이다.
- `gradingMode`는 `strict-output` 또는 `normalized-concept`다.
- `sourceStatus`는 `verified`, `reconstructed`, `conflicting` 중 하나다.

개인 학습 상태는 자격증별 localStorage 키에 저장한다.

```text
cert-study:v1:information-processing-engineer
```

저장하는 값은 Day 완료 여부, 현재 탭, 답안 초안, 모의고사 결과, 오답 이력, 오답 이유, 개인 메모, 카드 상태다. 데이터는 로그인이나 서버로 전송하지 않는다.

JSON 내보내기·불러오기를 제공한다. 자동 저장은 기본이며 백업은 브라우저 변경, 데이터 삭제, 기기 이동에 대비한 선택 기능이다.

## 오답과 복습

채점 후 틀린 문항은 자동으로 오답에 추가한다. 사용자는 `개념을 몰랐음`, `코드 추적 실수`, `계산 실수`, `문제를 잘못 읽음`, `답안 형식 실수`, `찍었음` 중 하나를 선택하고 필요하면 한 줄 메모를 남긴다.

오답은 1일·3일·7일 뒤 재풀이 대상으로 제안한다. 재풀이 이력은 덮어쓰지 않고 누적한다. 각 문항의 `다시 기억할 규칙`은 직접 작성한 해설에서 자동으로 제공하며 암기카드의 뒷면에 사용한다.

## 집중 모드와 접근성

기본 상태는 포트폴리오 공통 헤더를 유지한다. 문제풀이에서 집중 모드를 켜면 헤더와 주변 메뉴를 접고 `종료 · 남은 시간 · 현재 문항 · 문제 · 답안 · 이전/다음 · 제출`만 표시한다.

모든 조작은 키보드와 터치로 가능해야 한다. 터치 대상은 최소 44px로 두고, 답안 입력 오류와 자동 제출 결과는 화면에서 바로 확인할 수 있게 한다. 코드는 작은 화면에서 가로 스크롤을 허용하되 본문 전체에는 가로 스크롤을 만들지 않는다.

## 출처·업데이트 정책

- 블로그 전체 목차는 자료실에 연결하고, 해당 개념과 회차 페이지에서도 관련 링크를 다시 제공한다.
- 각 기출 회차는 원문 링크를 제공한다.
- 기출 내용은 기존 HTML, 공개 복원 글, 영상·텍스트 기록을 교차 확인한다.
- 출처가 다르거나 원문이 불완전하면 임의로 확정하지 않고 상태를 표시한다.
- 해설은 직접 작성하며, 기출 원문과 새 해설을 구분한다.
- 새 회차는 문제 데이터만 추가해 기존 화면과 학습 상태 모델을 재사용한다.

## 제외 범위

- 로그인, 계정, 서버 저장, 다른 사용자 관리
- Python 코딩테스트 학습 화면
- AI 자동 해설 생성
- 실시간 동기화와 푸시 알림
- 별도 FastAPI 또는 데이터베이스

## 완료 기준

1. 공개 Study 경로에서 데스크톱과 모바일 모두 사용 가능하다.
2. 8회차 160문제를 회차별로 풀고 150분 모의고사로 제출할 수 있다.
3. 이론과 코드 출력 채점 규칙이 구분되어 동작한다.
4. 오답, 복습 일정, 암기카드, Day 진행 상태가 자동 저장된다.
5. JSON 백업·복원이 상태를 보존한다.
6. 자료실의 전체 목차와 각 회차 원문 링크가 제공된다.
7. 문제의 시각 자료가 외부 페이지를 열지 않아도 풀이 가능한 형태로 보인다.
